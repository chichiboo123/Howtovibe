CHAPTER 01 · 원셰프의 바이브코딩

원셰프의 바이브코딩

AI와 함께, 교사가 직접 수업 도구를 만드는 시대가 왔습니다.

01

왜 지금, 바이브코딩?

수업 자료의 진화와 AI의 역할

▼
school

교실 사례: 수업 활동 앱

선생님이 직접 만든 모둠 활동 앱. 학생들이 스마트폰으로 접속해 실시간으로 결과를 공유합니다.

timer

당일 제작 가능

오늘 아이디어가 생겼다면, 오늘 웹앱을 완성할 수 있습니다. AI가 코드를 대신 작성해줍니다.

link

링크 하나로 공유

프린트 없이도 됩니다. 링크 하나를 공유하면 학생 누구나 접속할 수 있는 인터랙티브 수업 자료가 됩니다.

edit

내 수업에 딱 맞게

기성 플랫폼의 제약 없이, 내 학생들에게 완벽히 맞는 도구를 직접 만들 수 있습니다.

02

바이브코딩의 본질

코딩 기술보다 중요한 4가지 핵심 원칙

▼
03

바이브코딩의 장점

빠르고, 쉽고, 창의적인

▼
⚡

빠르다

아이디어에서 완성된 웹앱까지 단 하루면 충분합니다. AI가 코드를 대신 작성하기 때문에 개발 속도가 비약적으로 빨라집니다.

🙌

쉽다

코딩 지식이 전혀 없어도 됩니다. 원하는 것을 말로 설명하면 AI가 작동하는 코드를 만들어 줍니다. 누구나 시작할 수 있습니다.

✨

창의적이다

기성 플랫폼의 제약에서 벗어나 오로지 내 수업만을 위한 도구를 직접 만들 수 있습니다. 상상한 모든 아이디어를 현실로 만드세요.

"La perfection est atteinte, non pas lorsqu'il n'y a plus rien à ajouter, mais lorsqu'il n'y a plus rien à retrancher." "완벽함은 더 이상 보탤 것이 없을 때가 아니라,
더 이상 덜어낼 것이 없을 때 이루어진다."
— Antoine de Saint-Exupéry

history_edu 실제 교사 예시

"나는 초등학교 0학년 교사야야.

수업 시간에 학생들이 찬반 토론 의견을 제출하는 웹앱을 만들어줘.

- 학생이 이름과 의견(찬성/반대)을 선택하고 이유를 입력
- 제출 후 전체 결과를 막대 그래프로 표시
- 선생님 모드: 결과 초기화 버튼
- 모바일 기기 최적화
- HTML, CSS, JS 한 파일로 만들어줘"

desktop_windows 코드 실행하기 (2가지 방법)

방법 1: 로컬 파일 (가장 쉬움)
  1. AI 코드를 복사 → index.html 파일로 저장
  2. 파일을 더블클릭 → 브라우저에서 바로 실행
방법 2: Replit (설치 불필요, 즉시 공유)
  1. replit.com 접속 → 새 Repl 만들기
  2. 코드 붙여넣기 → Run 버튼 클릭
  3. 자동으로 URL 생성 → 학생들과 즉시 공유
