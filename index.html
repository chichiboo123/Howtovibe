교실 사례: 수업 활동 앱

선생님이 직접 만든 모둠 활동 앱. 학생들이 스마트폰으로 접속해 실시간으로 결과를 공유합니다.

⏱️

당일 제작 가능

오늘 아이디어가 생겼다면, 오늘 웹앱을 완성할 수 있습니다. AI가 코드를 대신 작성해줍니다.

🔗

링크 하나로 공유

프린트 없이도 됩니다. 링크 하나를 공유하면 학생 누구나 접속할 수 있는 인터랙티브 수업 자료가 됩니다.

✏️

내 수업에 딱 맞게

기성 플랫폼의 제약 없이, 내 학생들에게 완벽히 맞는 도구를 직접 만들 수 있습니다.

CHAPTER 02 · 밀키트

필요한 도구 준비하기

요리처럼, 좋은 도구가 있으면 더 쉽게 만들 수 있습니다. 역할별로 도구를 이해해보세요.

💡

아이디어 확장

수업 아이디어를 구체적인 기능으로 발전시키는 도구

ChatGPT
아이디어 브레인스토밍, 수업 활동 구체화, 프롬프트 초안 작성
Gemini
구글 워크스페이스 연동, 수업 계획서 분석, 아이디어 발전
⚡

코드 생성

아이디어를 실제 동작하는 코드로 만들어주는 핵심 도구

Claude (Anthropic) 추천
긴 코드 맥락 이해, 정확한 구현, 선생님 눈높이에 맞는 설명
Gemini Code
구글 생태계 친화적, 실시간 코드 수정 및 미리보기
🚀

앱 제작 및 배포

🎯 교사 활동 예시

학생들이 모둠별로 토론 결과를 제출하는 앱이 필요하다고 상상해보세요.

시각화 질문들
  • 학생이 이 앱에서 무엇을 입력하는가?
  • 선생님은 어떤 화면을 보는가?
  • 수업의 어느 단계에서 사용하는가?
💡 팁: 종이에 먼저 화면을 스케치해보세요. 그림이 있으면 AI에게 더 정확하게 설명할 수 있습니다.
I

Interact — AI와 대화하기

상상한 것을 AI에게 설명하고 코드를 받습니다

▼

📝 좋은 첫 프롬프트 구조

나는: [교사 / 교과목]
목적: [어떤 수업 활동에 쓸 것인지]
사용자: [학생 / 학년]
핵심 기능: [학생이 할 수 있는 것 3가지]
형식: HTML/CSS/JS 단일 파일

✍️ 실제 교사 예시

"나는 중학교 사회 교사입니다.

수업 시간에 학생들이 찬반 토론 의견을 제출하는 웹앱을 만들어줘.

- 학생이 이름과 의견(찬성/반대)을 선택하고 이유를 입력
- 제출 후 전체 결과를 막대 그래프로 표시
- 선생님 모드: 결과 초기화 버튼
- 모바일에서도 잘 보이게
- HTML, CSS, JS 한 파일로 만들어줘"
💡 팁: "나는 교사입니다"라고 명시하면 AI가 교육적 맥락을 더 잘 이해합니다.
B

Build — 구현하기

AI가 만든 코드를 실행하고 결과를 확인합니다

▼

🖥️ 코드 실행하기 (2가지 방법)

방법 1: 로컬 파일 (가장 쉬움)
  1. AI 코드를 복사 → index.html 파일로 저장
  2. 파일을 더블클릭 → 브라우저에서 바로 실행
방법 2: Replit (설치 불필요, 즉시 공유)
  1. replit.com 접속 → 새 Repl 만들기
  2. 코드 붙여넣기 → Run 버튼 클릭
  3. 자동으로 URL 생성 → 학생들과 즉시 공유

🐛 오류가 났을 때

"아래 오류가 발생했어. 고쳐줘:
[오류 메시지 붙여넣기]"
💡 팁: 오류 메시지를 그대로 복사해서 AI에게 붙여넣으면 대부분 해결됩니다.

📋 좋은 개선 요청 예시

❌ 막연한 요청

"학생들이 불편해했어. 고쳐줘"

✅ 구체적인 요청

"모바일에서 버튼이 너무 작아서 못 눌렀어. 버튼 크기를 2배로 키워줘"

🎓 배포 및 학생 공유

  1. GitHub Pages 또는 Vercel에 업로드
  2. 생성된 URL을 QR코드로 변환 (구글에서 "QR코드 생성기" 검색)
  3. 수업 자료에 QR코드 삽입 → 학생들이 스캔
💡 팁: 첫 번째 앱이 완벽하지 않아도 됩니다. 매 수업마다 조금씩 발전시키는 것이 핵심입니다.
